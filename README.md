# SIGLAC

Sistema Web de Gestión y Localización de Actas y Certificados Históricos de la UGEL N.° 08 Cañete.

## Estado del proyecto

En fase de diseño y preparación del entorno de desarrollo.

## Stack tecnológico previsto

- PHP
- Laravel
- MySQL
- Blade
- HTML
- Tailwind CSS
- JavaScript

## Estructura del proyecto

- `docs/01-requerimientos`: matriz de requerimientos y RF/RNF.
- `docs/02-analisis`: entrevistas, procesos y análisis.
- `docs/03-arquitectura`: arquitectura y entorno técnico.
- `docs/04-base-datos`: DER y diccionario de datos.
- `docs/05-mockups`: prototipos de interfaz.
- `docs/06-manuales`: manuales de usuario y técnicos.

## Ambientes

### Desarrollo
Equipo local de desarrollo.

### Producción
Servidor institucional de la UGEL N.° 08 Cañete.

## Seguridad

Las credenciales, contraseñas y archivos `.env` no deben almacenarse en el repositorio.
